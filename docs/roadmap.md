# AI 工程成长路线

## 长期方向

智能设备 + 视觉感知 + AI Agent + 企业系统工程化。

## 2026 当前阶段

Hello-Agent学习、ebo-mlops工程学习、Agent工程能力建设。
按完成标准推进，具体时间随实践结果调整。

| 阶段 | 学习内容 | 技术资产 | 完成标准 |
| --- | --- | --- | --- |
| L1 基础认知 | LLM、Prompt、Context、Structured Output | 概念笔记与最小实验 | 能解释输入输出并验证结构化输出 |
| L2 Agent 能力 | Hello-Agent 理论、Runtime、Agent Loop、Tool Calling、Memory、Planning | 章节代码、调用链与实验笔记 | 能追踪完整运行链路，验证工具与记忆行为 |
| L3 企业 Agent 工程 | MCP、RAG、LangGraph、Workflow、系统集成 | 自建集成示例与设计笔记 | 能解释权限边界与失败处理 |
| L4 工程化 | 评估、可观测性、权限、部署；视觉模型生命周期 | 脱敏工程笔记与自建验证案例 | 能解释数据、训练、评估、部署、监控与回滚的关联 |
| L5 系统设计 | Desk Butler、AI应用实践 | 个人项目、架构决策和复盘 | 完成可运行闭环并记录评估结果 |

## 两条学习主线

- Hello-Agent：每章选择一个场景，完成调用链分析、最小验证与复盘。
- ebo-mlops：理解数据管理、训练、模型版本、部署和工程协作；只沉淀脱敏笔记，不保存公司源码。
