# 五交易日短线计划规则

用户：5000元（最后确认）、空仓（最后确认）、深市主板、无创业板、每天数次看盘、能设置券商价格提醒与条件单。更新账户信息时服从用户新确认，不自行推算。

两种模式：强势股首次回踩后再次转强；平台初次突破后的确认。研究时可采用趋势、相对强弱、事件核验、量价和成本意识，但不能在失败后切换模式解释。稳定经营和半年报增长用于排雷，不能直接证明未来五日上涨。

交易前核查：
1. 同一时点的市场/板块强弱、个股1/3/5日表现，确认主线或独立催化。
2. 合法且可买的主板证券；ST、停牌、退市/无涨跌幅限制、上市初期复杂状态初期排除。
3. K线/分钟柱已完成且口径一致，回踩区和平台预先定义；当日高点不是天然压力。
4. 已公开公告原文及未来五日风险；缺重要信息时列候选，不称确认买点。
5. 失效价、目标依据、上限、整手数量和净赔率；到价提醒后人工复核，不盲买。

仓位先以合理失效距离反推；通常1500～2000元不是最低门槛，单只最多2500元、总仓位60%、通常一只。计划风险40～60元含费用滑点，净赔率原则上至少2；这些是初始管理参数，不是验证有效的策略。100股也超预算则放弃，不人为缩窄止损，不为凑赔率抬目标。

出场：价格结构失效，在可卖时按计划处理；买入后两个交易日无进展且模式转弱时退出；首笔实际成交日算第1天，最迟第5交易日计划退出。加仓不重置截止。目标到达或盈利结构破坏时退出，防守随确认的结构上移。小账户少拆单，不以高频做T变相补亏损仓。

条件单由用户配置；先核对触发与委托价格区别、有效期、可卖量、是否真支持互斥。当日新仓通常不能卖；跳空/跌停可令订单无法成交。不能声称计划风险是实际损失上限。部分成交、止盈止损残单、停牌或第5日未成交均记录异常。

滚动5交易日净亏损约150元时先暂停新仓并复盘，也可更早暂停。研究池按周检视，每天最多2个计划；临时重大风险可即时降级，不随一天涨跌来回删除/推荐同一股票。

每条计划需：生成与失效时间、模式、证据、入场触发、最高买价、数量/金额/占比、失效条件、目标、含费滑点净赔率、T+1、五日截止、数据缺项。未触发、取消和失败计划同样记录；先用20笔检查执行一致性，不足以宣称优势或胜率。
