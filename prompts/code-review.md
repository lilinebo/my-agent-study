# 代码评审 Prompt 模板

用途：代码评审。当前为基础模板，使用前替换占位内容。
配套方法：[code-review](../skills/code-review.md)。

## 模板

```text
变更目的：{{目的}}
评审范围：{{文件或差异}}
预期行为：{{行为}}
验证记录：{{已有测试与结果}}

只读评审差异与相关上下文，检查正确性、边界、权限与兼容性。
按影响排序输出问题、文件位置、触发条件、影响和修复建议。
区分已验证问题与潜在风险；没有发现问题时如实说明验证局限。
企业资料仅在授权环境使用，不上传公司源码或敏感内容。
```
