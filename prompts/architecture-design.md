# 架构设计 Prompt 模板

用途：架构设计。当前为基础模板，使用前替换占位内容。
配套方法：[architecture-review](../skills/architecture-review.md)。

## 模板

```text
业务场景：{{场景}}
系统边界：{{边界}}
规模与约束：{{规模、延迟、成本、环境}}
已有架构：{{脱敏描述或个人项目设计}}

明确需求缺口，输出模块职责、数据流、控制流与方案取舍。
覆盖失败恢复、权限、评估、可观测性和部署回滚；给出最小实现与验收指标。
未知需求明确标注，不虚构约束。
企业资料仅在授权环境使用，不上传公司源码或敏感内容。
```
