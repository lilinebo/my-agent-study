# 代码分析 Prompt 模板

用途：代码分析。当前为基础模板，使用前替换占位内容。
配套方法：[codebase-learning](../skills/codebase-learning.md)。

## 模板

```text
具体问题：{{问题}}
代码范围：{{授权范围}}
已知现象：{{现象}}
已有证据：{{日志或复现，须脱敏}}

先只读分析问题相关入口、调用链与状态变化。
输出有位置依据的发现、待验证假设、验证步骤和局限；未经授权不修改代码。
企业资料仅在授权环境使用，不上传公司源码或敏感内容。
```
