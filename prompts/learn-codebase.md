# 学习陌生代码库 Prompt 模板

用途：学习陌生代码库。当前为基础模板，使用前替换占位内容。
配套方法：[codebase-learning](../skills/codebase-learning.md)。

## 模板

```text
学习目标：{{目标}}
代码范围：{{个人代码或明确授权范围}}
运行条件：{{环境与限制}}

先只读检查，输出项目地图；选择一个场景分析调用链，再深入关键模块。
结论标注文件位置，区分事实和推测，提出最小验证方案与复盘问题。
企业资料仅在授权环境使用，不上传公司源码或敏感内容。
```
