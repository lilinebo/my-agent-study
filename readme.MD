# My AI Engineering Journey

我的长期 AI 工程学习与技术资产仓库。

## 目标方向

成为：智能设备 + 视觉感知 + AI Agent + 企业系统工程方向工程师。

## 当前阶段

2026：

- Hello-Agent学习
- ebo-mlops工程学习
- Agent工程能力建设

当前重点（2026.10）：理解 Agent 运行机制、学习企业视觉模型生命周期、建立可复用的 AI 工程 Skill 体系。

## 学习路线

1. **L1 基础认知**：LLM、Prompt、Context、Structured Output。
2. **L2 Agent 能力**：通过 Hello-Agent 学习理论、Agent Loop / Runtime、Tool Calling、Memory、Planning。
3. **L3 企业 Agent 工程**：MCP、RAG、LangGraph、Workflow，以及工具与企业系统集成。
4. **L4 工程化**：Evaluation、Observability、Permission、Deployment；通过 ebo-mlops 学习数据管理、训练、视觉模型部署及生命周期管理。
5. **L5 系统设计与实践**：构建完整 AI 系统，通过 Desk Butler 和 AI应用实践串联智能设备、视觉感知与 Agent 能力。

阶段产出与验收方式见 [成长路线](docs/roadmap.md)。

## 学习原则

- 不追求快速浏览
- 深入理解系统设计
- 每个学习主题留下技术资产
- 通过代码实践形成能力

## 维护方式

每个主题按“问题 → 理解 → 实践验证 → 复盘 → 可复用资产”推进。
笔记注明日期、公开来源、验证方式和未解决问题，区分事实与推测。
Skill 是工作方法，Prompt 是调用模板；验证过的方法再沉淀为长期资产。

ebo-mlops-learning 仅保存学习笔记，禁止放入公司源码、内部数据、密钥或未经授权的内部资料。技术经验使用脱敏描述和自建示例表达。
