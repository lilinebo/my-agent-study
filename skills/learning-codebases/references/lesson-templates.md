# Lesson Templates

Use only the template needed for the current output. Translate labels into the user's language.

## Project compass

- **Depth mode**
- **Project purpose**
- **Input -> process -> output**
- **Active entry point and evidence**
- **Five to twelve key modules and relationships**
- **Code-confirmed / runtime-confirmed / documented / inferred / unknown**
- **Recommended first learning path**
- **Why this pass stopped**
- **What would justify going deeper**

End with one choice: follow the proposed flow, inspect one module, run a safe check, or let the user ask a question.

## Code-tour stop

- **Path and symbol**
- **Role in the current flow**
- **Input state**
- **Decision or transformation**
- **Output state and next destination**
- **One beginner concept**
- **One learner-check question**

## Learning checkpoint

- **Completed**
- **You should now be able to**
- **Still uncertain**
- **Recommended next unit**

Do not repeat earlier detail; refer to the established compass or flow.

## Session end

- **Learned today**
- **Key paths and symbols**
- **Concepts:** Initial / Understanding / Mastered
- **Open questions**
- **Recommended next session**
- **One review task under five minutes**

## Optional learning state

Create a file only after the user approves both persistence and location.

- **Current goal**
- **Repository path and revision**
- **Project compass**
- **Completed flows**
- **Concept status**
- **Open questions and verification needs**
- **Suggested next step**
- **Short session log**

For private projects, recommend storage outside the repository and record concepts, paths, symbols, and the learner's own words rather than substantial source excerpts.

On resumption, revalidate repository path, revision, active entry point, and the previously studied flow before relying on saved state.
