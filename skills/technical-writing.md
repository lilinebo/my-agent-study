# 技术写作方法

## 用途

把学习结果整理为可查找、可复现、可复用的技术资产。

## 工作步骤

1. 明确读者、问题、范围与核心结论。
2. 按“问题 → 原理 / 设计 → 实践 → 结果 → 局限”组织内容。
3. 标注公开来源、代码位置和实验条件，区分事实与推测。
4. 检查示例可复现性，删除敏感信息和未经授权的内部内容。
5. 添加日期、主题与关联资产链接，保留未解决问题。

## 文档模板

- 日期 / 标题 / 读者：待填写
- 问题与范围：待填写
- 核心结论：待填写
- 原理与设计取舍：待填写
- 示例、验证与结果：待填写
- 局限与下一步：待填写
- 公开来源与关联资产：待填写
